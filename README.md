# 🧮 Calculator Web Application

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

This project performs basic arithmetic operations with a clean and user-friendly interface.

## 📌 Project Overview

This calculator is designed as a beginner-friendly web development project to practice:

- HTML structure
- CSS styling and responsive design
- JavaScript programming
- DOM manipulation
- Event handling
- Git and GitHub
- GitHub Pages deployment

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- 🗑️ Clear button
- ⌫ Delete button
- 🌙 Dark mode
- ⌨️ Keyboard support
- 📜 Calculation history
- 📱 Responsive design for mobile devices
- ⚠️ Basic error handling

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub**
- **GitHub Pages**
